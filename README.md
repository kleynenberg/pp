# Personal Projects — Steven Kleynenberg

Dit is de broncode van **[pp.kleynenberg.com](https://pp.kleynenberg.com/)**: een overzicht van onafhankelijke onderzoeksprojecten, wiskundige visualisaties, interactieve webapplicaties (PWA's) en systeemexperimenten van Steven Kleynenberg.

## Inhoud van deze repository

* **`index.html`** — De hoofdpagina en projectindex op `pp.kleynenberg.com`.
* **`fract/`** — **Fractinity**: een interactieve 2D/3D-fractalverkenner, Progressive Web App (`pwa/`), Python-renderengine (`server/fractal_server.py`), bijbehorende LaTeX-documentatie (`server/latex/fractal.tex`) en visualisaties (`art/`).
* **`llms.txt` & `llms-full.txt`** — Gestructureerde, machine-leesbare projectbeschrijvingen en documentatie voor taalmodellen en AI-indexering.
* **`CNAME`** — Domeinkoppeling voor GitHub Pages (`pp.kleynenberg.com`).

## Uitgelicht project: Fractinity (`fract/`)

Fractinity combineert wiskundige iteratie met directe visuele verkenning in de browser en op de server:

* **Web & PWA (`fract/pwa/`)** — Lichtgewicht Progressive Web App met offline ondersteuning (`manifest.json`, `sw.js`) zonder zware externe frameworks.
* **Server & Renderengine (`fract/server/`)** — Python-backend (`fractal_server.py`) voor rekenintensieve fractalgeneratie en videorendering.
* **Wiskundige achtergrond (`fract/server/latex/`)** — Formele uitwerking van de gebruikte formules en algoritmen in LaTeX (`fractal.tex` en `fractal.pdf`).
